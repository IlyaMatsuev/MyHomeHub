# Zigbee2MQTT Configuration

This directory contains the Zigbee2MQTT configuration files.

## Files

- `configuration.example.yaml` - Template with `__VAR__` placeholders, used to create a configuration file for Z2M
- `configuration.yaml` - Rendered config consumed by Zigbee2MQTT (NOT committed to git, generated by `npm run zigbee:config:sync` from the template and `.env`)

## Setup

1. Specify all `Z2M_*`, `MQTT_*`, and `ZIGBEE_*` variables in `.env` file in the root as shown in [.env.example](../../.env.example).
2. Then, make sure [MQTT broker](../mqtt) is started.
3. Start the Z2M service with: `npm run zigbee:start`

## Hardware

This configuration is designed to use a network Zigbee coordinator, such as SONOFF Dongle Max.

### Coordinator Address

Set `Z2M_COORDINATOR_URL` to the coordinator's TCP address (for the dongle above you can reach it in the network via `tcp://Dongle-M.local:6638`), and reserve its IP in the router's DHCP settings so it never changes.
