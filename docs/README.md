## Configuration

Configuration capabilities are provided by using the Custom Metadata Type `Config__mdt`. Each record represents a piece of configuration. All existing records are described in the table below:

| Label      | Name           | Default Value | Type    | Description   |
| ---------- | -------------- | ------------- | ------- | ------------- |
| Some field | SomeField\_\_c | 100           | Integer | Just a number |
